## 1. SEO Strategy

### 1.1 Technical SEO

#### Core Web Vitals Targets

| Metric | Target | Description |
|---|---|---|
| LCP (Largest Contentful Paint) | ≤ 2.5 seconds | Main product image or hero should load fast |
| INP (Interaction to Next Paint) | ≤ 200 milliseconds | Buttons, filters, add-to-cart must respond instantly |
| CLS (Cumulative Layout Shift) | ≤ 0.1 | No unexpected layout jumps from ads, images, or fonts |
| TTFB (Time to First Byte) | ≤ 800 milliseconds | Server response time (Vercel edge network helps) |
| FCP (First Contentful Paint) | ≤ 1.8 seconds | First visible content should appear quickly |

#### Mobile-First Implementation Checklist

- [ ] Design and test on 375px viewport first (iPhone SE baseline)
- [ ] Touch targets minimum 44×44px for all interactive elements
- [ ] No horizontal scroll on mobile
- [ ] Font sizes minimum 16px for body text (prevents iOS auto-zoom)
- [ ] Responsive images with `srcset` and `sizes` attributes
- [ ] Google Search Console — set up and verify mobile usability report

#### Structured Data Markup (Schema.org)

| Schema Type | Pages to Apply | Key Properties |
|---|---|---|
| `Product` | All product pages | name, description, image, offers (price, priceCurrency, availability), brand, sku, aggregateRating |
| `BreadcrumbList` | All pages below home | itemListElement with position and name |
| `FAQPage` | FAQ, product pages (Q&A) | mainEntity with Question and acceptedAnswer |
| `Article` | Blog posts | headline, author, datePublished, image, publisher |
| `LocalBusiness` | Homepage, About | name, address (Bengaluru), telephone, openingHours, geo, url |
| `Review` / `AggregateRating` | Product pages | ratingValue, reviewCount, bestRating |
| `Organization` | Homepage | name, url, logo, sameAs (Instagram URL, WhatsApp) |
| `WebSite` | Homepage | name, url, potentialAction (SearchAction for sitelinks search box) |

#### Technical Implementation

```
XML Sitemap:
- /sitemap.xml — auto-generated by Next.js (next-sitemap package)
- Include: all product URLs, category URLs, blog posts, static pages
- Exclude: /checkout, /account, /admin, /api/*
- Submit to Google Search Console and Bing Webmaster Tools

Robots.txt:
- Disallow: /checkout/, /account/, /admin/, /api/
- Allow: /api/og/ (Open Graph image generation if used)
- Sitemap: https://www.navacreations.in/sitemap.xml

Canonical URLs:
- Add rel="canonical" on every page
- Filter and sort pages: canonical → base category URL
- Paginated pages: rel="next" and rel="prev" (or canonical to page 1)

Hreflang:
- English only initially: <link rel="alternate" hreflang="en-IN" href="..." />
- Add Hindi/Kannada pages only when content is genuinely translated
```

#### Image Optimisation

- [ ] Use Next.js `<Image>` component (automatic WebP conversion, lazy loading)
- [ ] Product images: 800×800px minimum, optimised < 150KB per image
- [ ] Alt text: descriptive, keyword-aware — e.g., `"Gold-tone Kundan bangle set with green stones — NAVA CREATIONS"`
- [ ] Avoid keyword-stuffed alt text; describe the image naturally
- [ ] Use `loading="eager"` for hero/above-fold images, `loading="lazy"` for below-fold
- [ ] Generate `placeholder="blur"` for perceived performance

### 1.2 Product Page SEO

#### Keyword Research Approach

**Tools**: Google Keyword Planner (free with Google Ads account) · Ubersuggest · Google Search (autocomplete + People Also Ask) · Google Trends India

**Research Process**:
1. Seed keywords: start with product names (bangles, Kundan bangles, bridal bangles, hair clips India)
2. Expand with location: "bangles Bengaluru", "buy bangles online India"
3. Check search intent: informational (how to / guide) vs transactional (buy / price / shop)
4. Prioritise long-tail keywords with lower competition for a new site
5. Record in a tracking spreadsheet: Keyword | Monthly Volume | Competition | Intent | Target Page

|---|---|---|---|

#### Product Page Title Format

```
[Product Name] | [Category] | NAVA CREATIONS
Example: "Gold Kundan Bangle Set with Emerald Stones | Bridal Bangles | NAVA CREATIONS"
```

- Max 60 characters for display (search results may truncate beyond this)
- Include primary keyword naturally
- Brand name at end (consistent across all pages)

#### Meta Description Template

```
[Compelling description of product — benefit + material + occasion]. [Call to action]. Free shipping on orders above ₹[X]. Shop NAVA CREATIONS — handmade accessories from Bengaluru.
```

- Max 155–160 characters
- Include keyword naturally; not keyword-stuffed
- Unique for each product — do NOT duplicate

## 2. Social Media Strategy — Instagram-First

### 2.1 Content Pillars

| Pillar | Description | Approx. % of Content | Examples |
|---|---|---|---|
| **Product Showcase** | High-quality product photos and videos; new arrivals, bestsellers | 35% | Flat-lay product photos, close-up detail shots, variant showcases |
| **Styling and Inspiration** | How to style accessories; outfit pairings; occasion styling | 25% | Styling tips for festivals, bridal look inspiration, everyday styling |
| **Behind the Scenes** | Craft process, packaging, behind-the-brand moments | 15% | Packaging products, raw material photos, studio shots |
| **Customer Features** | User-generated content; customer photos; testimonials | 15% | Repost customer selfies, unboxing moments, tagged photos |
| **Festival and Occasion Content** | Season-specific, timely content | 10% | Diwali wishes, Navratri countdown, Karva Chauth collections |

### 2.2 Post Types and Cadence

| Post Type | Frequency | Purpose |
|---|---|---|
| Feed Posts (Carousels) | 3–4 per week | Main product display; carousels drive saves and shares |
| Feed Posts (Single Image) | 2–3 per week | Lifestyle, behind-the-scenes, quotes |
| Reels | 2–3 per week | Highest reach; styling videos, product reveals, process videos |
| Stories | Daily (5–10 stories) | Engagement polls, Q&A, behind-the-scenes, links to website |
| Lives | Monthly (or for launches) | Festival launches, Q&A sessions, bridal consultations |

### 2.3 Reels Strategy

Reels receive the highest organic reach on Instagram. Priority content:

- **"5 ways to style these bangles"** — quick cut, trending audio
- **"This or That"** — comparison between two collections
- **Packing orders** — satisfying packing reels with text overlay
- **New arrival reveals** — dramatic product reveal with music
- **Festival countdown** — 3 days to Diwali: suggested daily looks
- **Process videos** — if handmade: show craft steps (if applicable and confirmed)

> [!IMPORTANT]
> Do NOT show or claim handmade processes unless the business owner confirms the products are handmade in-house. This is flagged as an open question in OPEN_QUESTIONS.md.

### 2.4 Instagram Shopping Setup

| Step | Requirement | When |
|---|---|---|
| Convert to Instagram Business Account | Must have business account | Now (before website launch) |
| Connect to Facebook Page | Required for Meta Commerce Manager | Now |
| Set up Meta Commerce Manager catalogue | Product catalogue uploaded via CSV, API, or Meta Pixel | Before or at website launch |

> Instagram Shopping requires a connected Facebook Page, a commerce catalogue, and approval from Meta. Approval timeline: 1–4 weeks. Some accounts in India face delays. Apply early.

**Research hashtags** before using — check volume and engagement in Instagram search.

### 2.7 Transition Strategy: DM-Ordering → Website Ordering

This is critical — NAVA CREATIONS' current customers order via DM. The transition must be gradual and customer-friendly.

**Phase 1 — Soft Introduction (1 month before launch)**:
- Begin mentioning "website launching soon" in Stories and posts
- Add countdown to bio
- Collect email addresses from interested followers ("DM us your email to get early access")

**Phase 2 — Launch Week**:
- Announce website launch with Reel + carousel post
- Offer launch discount (e.g., 10% off first website order with code NAVALAUNCH)
- Stories: step-by-step "how to order on the website" walkthrough

**Phase 3 — Ongoing Reinforcement (3 months post-launch)**:
- For every DM order enquiry, reply with product link: "Here's the direct link to order: [URL]"
- Continue to accept DM orders during transition but gently direct to website
- Celebrate milestones: "100 website orders!" — builds social proof

**Phase 4 — Full Migration (6 months post-launch)**:
- DM orders redirect fully to website
- WhatsApp only for custom/bulk enquiries

### 2.8 WhatsApp Status Updates

- Post product photos, new arrivals, and sale announcements to WhatsApp Status daily
- Include swipe-up style CTAs: "Link in bio" or "Message us to order"
- After website launch: include direct product links in Status captions

## 3. WhatsApp Marketing

### 3.1 WhatsApp Business vs WhatsApp Business API

| Feature | WhatsApp Business App | WhatsApp Business API (via BSP) |
|---|---|---|
| Cost | Free | Paid per conversation (₹0.35–₹0.70 per conversation approx. — verify current pricing) |
| Broadcast lists | Up to 256 contacts per list | Unlimited; requires opt-in consent |
| Automation | Basic auto-reply only | Full chatbot, automated flows, integrations |
| Multiple agents | No (single device) | Yes (team inbox) |
| Analytics | Basic | Delivery, read, response rates |
| When to use | Now — small scale | When monthly orders exceed ~100; when team grows |

**Recommendation**: Use WhatsApp Business App now. Migrate to API (via Interakt, Wati, or Gupshup) once business volume justifies the cost.

### 3.2 Broadcast Lists

> [!CAUTION]
> WhatsApp's Terms of Service require that recipients have opted in to receive broadcasts. Broadcasting to contacts who have not consented can result in account bans. Always obtain explicit consent before adding to a broadcast list.

| Broadcast List | Audience | Content |
|---|---|---|
| New Arrivals | Opted-in customers who want new arrival alerts | New product photos, prices, website links |
| Sale and Offers | Opted-in bargain shoppers | Flash sales, festival offers, coupon codes |
| Bridal Enquiries | Engaged/bridal customers | Exclusive bridal previews, consultation offers |
| Return Gift Buyers | Bulk/event buyers | Seasonal curated gift sets, bulk pricing |
| VIP Repeat Customers | 3+ order customers | Early access, loyalty offers, thank-you messages |

**Consent collection**: Add WhatsApp opt-in checkbox on website checkout and account registration. Text: *"I agree to receive order updates and promotions via WhatsApp. I can unsubscribe at any time."*

### 3.3 Automated Responses

Set up in WhatsApp Business App Settings:

| Trigger | Auto-Response Message |
|---|---|
| Any new message | "Hi! Welcome to NAVA CREATIONS 🌸 We'll reply within 2 hours. Browse our collection: [website link]. For orders, visit our website or tell us what you're looking for!" |
| Away message (outside hours) | "We're offline right now. We reply during 10 AM – 7 PM IST. Leave your message and we'll get back to you! Browse 24/7: [website link]" |
| Keywords: "price" / "cost" | "Our prices are listed on our website with all details: [link]. Feel free to ask if you need help finding anything!" |
| Keywords: "size" / "measure" | "Here's how to measure your bangle size: [size guide link]. Or DM us your measurement and we'll guide you!" |

### 3.4 Order Workflow via WhatsApp

**Before website**: Accept orders via DM → manual invoicing → UPI payment → dispatch
**After website launch (transition period)**: DM received → reply with product link → customer orders on website → automated WhatsApp order confirmation (via website integration)

**Post-launch automation** (WhatsApp Business API when scaling):
- Order placed → automatic WhatsApp: "Order #[X] confirmed! Estimated delivery: [date]."
- Order shipped → "Your order is on the way! Track here: [link]"
- Order delivered → "Your NAVA CREATIONS order has been delivered. We'd love your feedback!"

## 4. Email Marketing

### 4.1 Platform Recommendation

| Platform | Free Tier | Best For | Recommendation |
|---|---|---|---|
| **Brevo (formerly Sendinblue)** | 300 emails/day, unlimited contacts | Transactional + marketing emails | ✅ **Recommended — better transactional email support** |

### 4.2 Welcome Email Series (3 Emails)

| Email | Timing | Subject | Purpose |
|---|---|---|---|
| **Email 1** | Immediately on sign-up | "Welcome to NAVA CREATIONS — Your first gift inside 🎁" | Brand introduction + welcome discount (10% off first order) |
| **Email 2** | Day 3 | "Our story — handmade with love in Bengaluru" | Brand narrative, product categories, social proof |
| **Email 3** | Day 7 | "Your exclusive code expires soon — don't miss out" | Reminder of welcome discount + urgency |

**Email 1 Content Outline**:
- Warm welcome from founder
- Brand promise (1–2 sentences)
- Welcome discount code with expiry
- 3 category highlights with photos
- Instagram follow CTA

### 4.3 Abandoned Cart Email

| Email | Timing | Subject | Content |
|---|---|---|---|
| **Cart Reminder** | 1 hour after cart abandoned | "You left something beautiful behind 🌸" | Product image, name, price, direct "Complete Purchase" button, trust signals (easy returns, secure payment) |

> [!TIP]
> A single abandoned cart email at 1 hour typically recovers 5–8% of abandoned carts for small e-commerce. Add a second email at 24 hours with a small offer (5% off) if budget allows.

## 5. Analytics Measurement Plan

### 5.1 GA4 Event Tracking

| Event Name | Trigger | Key Parameters | Why Track |
|---|---|---|---|
| `view_item` | Product page load | `item_id`, `item_name`, `price`, `item_category`, `item_brand` | Product interest; identify popular products |
| `add_to_cart` | "Add to Cart" button click | `item_id`, `item_name`, `quantity`, `price`, `item_category` | Purchase intent; identify high-interest products |
| `remove_from_cart` | Remove item from cart | `item_id`, `item_name` | Cart friction analysis |
| `begin_checkout` | Checkout page load / step 1 | `cart_value`, `num_items`, `coupon` | Funnel drop-off analysis |
| `add_payment_info` | Payment method entered | `payment_type` | Payment method preference |
| `add_shipping_info` | Shipping details confirmed | `shipping_tier` (standard/express) | Shipping preference |
| `purchase` | Order confirmation page | `transaction_id`, `value`, `tax`, `shipping`, `currency`, `items[]` | Conversion; revenue tracking |
| `payment_failed` | Payment failure response | `payment_method`, `amount`, `error_code` | Payment friction; identify failure reasons |
| `search` | Search executed | `search_term`, `results_count` | Discovery behaviour; content gaps |
| `view_item_list` | Category/collection page | `item_list_name`, `items[]` | Category popularity |
| `view_wishlist` | Wishlist page opened | `wishlist_count` | Engagement; demand signals |
| `custom_enquiry` | Enquiry form submitted | `enquiry_type` (custom/bulk/bridal), `product_reference` | Lead generation quality |
| `size_guide_view` | Size guide page/modal opened | — | Support content usage |
| `coupon_applied` | Valid coupon entered | `coupon_code`, `discount_value` | Promotion effectiveness |
| `share` | Product share button | `method` (WhatsApp/copy link), `item_id` | Viral potential |
| `login` | User logs in | `method` (email/google) | User authentication |
| `sign_up` | Account created | `method` | Acquisition quality |

### 5.2 Conversion Funnel

```
Homepage / Product Page (view_item)
        ↓
Add to Cart (add_to_cart)
        ↓
Begin Checkout (begin_checkout)
        ↓
Shipping Info (add_shipping_info)
        ↓
Payment Info (add_payment_info)
        ↓
Purchase (purchase)
```

**Key funnel metrics to monitor**:
- Cart abandonment rate: `add_to_cart` → `begin_checkout`
- Checkout abandonment rate: `begin_checkout` → `purchase`
- Payment failure rate: `add_payment_info` → `purchase`

## 7. Marketing Budget Framework

### 7.1 Organic-First Strategy (Months 1–6)

> [!IMPORTANT]
> As a solo-operated small business in Phase 0 / early launch, **prioritise organic channels before paid advertising**. Build a solid organic foundation: a well-optimised website, quality product photos, consistent Instagram presence, and customer reviews before spending on ads. Organic is slower but free and sustainable.

| Channel | Investment Required | Timeline to See Results |
|---|---|---|
| Instagram (organic) | Time only — 1–2 hours/day | 3–6 months for compounding growth |
| WhatsApp (existing customers) | Free | Immediate |
| SEO (blog + product pages) | Time + content writing | 3–9 months for organic traffic |
| Email marketing | Brevo free tier | Builds over 6–12 months |
| Google Shopping (free listings) | Setup time only | 2–4 weeks after Merchant Center approval |
| Pinterest | Setup time + weekly pinning | 3–6 months |

**Recommended budget — Months 1–6**: ₹0 paid ads · Invest in photography (₹5,000–₹15,000 for quality product shoot) · Domain + hosting (Vercel free tier)

### 7.2 When to Start Google Shopping Ads

**Trigger conditions** (all should be true before starting):
- [ ] Website live for at least 2 months with real organic traffic
- [ ] Product pages have quality photos, descriptions, and reviews
- [ ] Google Merchant Center approved with product feed live
- [ ] Free Google Shopping listings have been generating clicks
- [ ] Monthly revenue from organic ≥ ₹20,000 (indicates product-market fit)
- [ ] Monthly advertising budget available: minimum ₹5,000–₹10,000/month

**Starting strategy**: Begin with Smart Shopping campaign, ₹200–₹300/day budget, only on top-5 products. Measure ROAS (Revenue / Ad Spend) > 3× before scaling.

### 7.3 When to Start Instagram / Facebook Ads

**Trigger conditions**:
- [ ] Organic Instagram content is performing (average 3–5% engagement rate)
- [ ] Website live with checkout functional and tested
- [ ] Meta Pixel installed and tracking conversions correctly
- [ ] Product catalogue connected to Meta Commerce Manager
- [ ] At least 20 customer reviews on the website (social proof)
- [ ] Monthly advertising budget: minimum ₹5,000–₹10,000/month

**Starting strategy**: Retargeting first (cheapest, highest ROAS) — retarget website visitors and cart abandoners. Then prospecting to lookalike audiences from existing customer list.

### 7.4 Customer Acquisition Cost (CAC) Expectations

| Channel | Typical CAC Range (India, fashion/accessories) | Notes |
|---|---|---|
| Organic Instagram | ₹0 direct (time cost) | Hard to measure precisely |
| Email marketing | ₹50–₹150 | Low cost once list is built |
| Google Shopping ads | ₹150–₹500 | Varies greatly by product and competition |
| Instagram / Facebook ads | ₹200–₹600 | Higher for cold audiences; lower for retargeting |
| WhatsApp (existing customers) | Near ₹0 | Highest ROI channel |

> [!NOTE]
> These CAC figures are **illustrative industry estimates** for Indian fashion e-commerce. Actual CAC for NAVA CREATIONS will depend on product price, ad creative quality, targeting, and seasonality. Measure CAC monthly: `Total Marketing Spend ÷ New Customers Acquired`.

**When to measure CAC**: Only meaningful after 3 months of consistent ad spend. First 3 months are learning and optimisation.

**Target CAC ceiling**: CAC should be less than 30% of Average Order Value (AOV). If AOV is ₹800, target CAC < ₹240. Adjust if LTV (lifetime value) is significantly higher due to repeat purchases.
